## 5. PDF Sizing — Make Everything Fit Perfectly

The #1 mistake new sellers make is uploading images that print weird (cut off, wrong size, blurry). Follow these rules and yours will be perfect every time.

### Target Print Specs
| Spec | Value | Why |
|------|-------|-----|
| Paper size | **US Letter, 8.5 × 11 inches** | Standard for US/Canada buyers |
| Orientation | **Portrait** | Coloring pages always look better portrait |
| Resolution | **300 DPI** | Sharp print, no pixelation |
| Pixel dimensions | **2550 × 3300 px** | 8.5 × 300 = 2550, 11 × 300 = 3300 |
| Color mode | **Black & White (or RGB with pure black/white)** | Saves ink for the buyer |
| Margins | **0.5 inch white border** on all sides | Looks professional, prevents edge cropping |

### Step-by-Step: Turn DALL-E images into a print-ready PDF (100% free tools)

**Option 1 — Google Docs (easiest, no install)**

1. Open [Google Docs](https://docs.google.com) → blank doc.
2. **File → Page setup** → set page size to **Letter (8.5 × 11)**, all margins to **0.5 inch**, orientation **Portrait**.
3. **Insert → Image → Upload from computer** → drop your DALL-E coloring page in.
4. Click the image → resize so it fills the page within the margins (drag corners while holding Shift to keep proportions).
5. Press `Ctrl+Enter` (page break) → repeat for next image.
6. Once all 100 pages are in: **File → Download → PDF Document (.pdf)**. Done.

**Option 2 — Canva Free (a bit more polished)**

Canva's free tier *does* let you build PDFs and add images — you only need the paid version for premium templates and Magic-resize. So:

1. Go to canva.com → "Create a design" → search **"US Letter"** (free template).
2. Drag your DALL-E images in → resize to fill page → add page → repeat.
3. **Share → Download → PDF Print** → done. Free.

**Option 3 — Microsoft Word / LibreOffice Writer (if you prefer offline)**

Same principle: Letter size, 0.5" margins, insert image fitted to page, save as PDF.

### Resizing DALL-E Images Before You Insert

DALL-E gives you 1024×1024 (square) or 1024×1792 (tall). Both look fine on an 8.5×11 page, but for the cleanest result:

1. Tell ChatGPT: *"Generate this image in tall portrait orientation, 1024×1792."*
2. If you got a square one and want to upgrade quality before printing, use **[upscayl.org](https://upscayl.org/)** (free desktop app, AI upscaler) to bring it to 2048×2048 or higher. Sharper print = better reviews.
